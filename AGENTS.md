# Agent instructions

- Work only on the `agent` branch unless the user explicitly requests another branch. Before touching another branch, warn the user and record the exception in `lab-notes.md`.
- Append short, timestamped, factual entries to `lab-notes.md` for meaningful commands, decisions, and outcomes.
- After each logically complete unit of work, commit the changes, update `lab-notes.md` with the result and commit, and push the `agent` branch to `origin` so an interrupted SLURM session loses as little work as possible.
- Before ending a task, commit and push all intended work and add a final summary entry to `lab-notes.md`.
